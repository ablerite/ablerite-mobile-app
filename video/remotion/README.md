# Ablerite onboarding video

Two editable 1080x1920 Remotion videos highlighting Ablerite's core benefits.

## Commands

```bash
npm install
npm run studio
npm run render
npm run render:interactive
npm run still
```

Rendered files are written to `out/`.

`AbleriteInteractiveOnboarding` is an expanded 52-second mobile onboarding story. Every section appears inside a mobile handset UI with progress feedback and animated taps. It introduces Ablerite as a holistic self-growth and development suite, features brain training, visualization, manifestation and Diana Life Assistant, then recreates the app's three-screen onboarding flow with selection feedback, page transitions, and completion state.

`AbleriteOnboarding` is the original 30-second benefit-led cut.
